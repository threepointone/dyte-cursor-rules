# @dytesdk/cursor-rules

Cursor rules for Dyte - a managed media backend solution that provides high-quality voice/video capabilities with React primitives.

## Overview

Dyte provides a comprehensive media backend solution including:

- SFUs (Selective Forwarding Units)
- TURN servers
- Recording capabilities
- RTMP support

The platform offers:

- Low latency (average 200ms including signaling)
- Scalability (up to 10k viewers per webinar)
- Drop-in UI kit that handles WebRTC edge cases
- Automatic server elasticity and regional routing
- Fine-grained customization options
- Built-in compliance (ISO 27001, HIPAA-ready, GDPR)

## Installation

```bash
npm install @dytesdk/cursor-rules
```

## Key Features

- **Ship Fast**: Drop-in UI kit that handles WebRTC edge cases
- **Scale Automatically**: Server elasticity and regional routing
- **Fine-grained Customization**: Theme tokens, headless hooks, REST APIs
- **Compliance Baked In**: ISO 27001, HIPAA-ready, GDPR compliant

## Use Cases

- **Ed-Tech**: Virtual classrooms with breakout rooms, polls, and raise-hand features
- **SaaS Support**: Click-to-call functionality with screen sharing
- **Tele-Health**: Doctor-patient calls with waiting rooms and file sharing
- **Virtual Events**: Large-scale webinars with low-latency Q&A
- **Gaming**: Voice communications overlay in React canvas

## Integration Options

1. **Full UI**: Complete interface with minimal code
2. **Composed UI**: Custom layouts using individual components
3. **Headless**: Use hooks for custom implementations
